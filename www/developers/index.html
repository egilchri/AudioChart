Nautical charts, spoken aloud.

AudioChart is a voice-interface PWA that reads nautical chart data — bearings, hazards, buoys — aloud, and keeps working fully offline once charts are downloaded. The code is public; here's how it's put together.

Architecture

Chart data in, spoken bearings out.

The repo is organized as a pipeline: raw chart data is prepared once, served to clients, and consumed by an installable offline web app.

01

preprocess/

Prepares raw nautical chart data — buoys, hazards, depths, coastline — into the format the app consumes.

→
02

server/

Backend service that fronts the prepared chart data for the client.

→
03

www/

The installable PWA — map, voice output, offline chart caching, and the on-screen controls.

→
04

.github/workflows/

CI that builds and deploys the app to GitHub Pages on every push to main.

How it's built

Developed in the open, with Claude Code.

Every feature, fix, and chart region added to AudioChart is tracked in the open — from the original offline-PWA groundwork to the latest chart data fixes. Browse the commit log to see the app's actual development process, not just the finished product.
