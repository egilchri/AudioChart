# AudioChart

Get info from nautical charts via a voice interface — a PWA for real-time bearings, hazard checks, auto-routing, and more, built to keep working after you lose signal at the dock.

- **App:** https://egilchri.github.io/AudioChart/
- **For sailors:** https://egilchri.github.io/AudioChart/sailors/
- **For developers:** https://egilchri.github.io/AudioChart/developers/
